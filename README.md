# Dream Spark Travel

Монголын нутгийн аялалын компанийн **олон хэлт (MN / EN / KR)**, **бүрэн динамик** вэбсайт.
Аялал, зургийн цомог, холбоо барих мэдээлэл нь admin самбараас удирдагдана. Захиалгын маягт
байхгүй — зочин KakaoTalk, Instagram, Naver блог зэрэг **ердийн сувгаараа** шууд холбогдоно.

Агуулга нь компанийн Instagram (@dreamspark_travel) болон Naver блогийн өөрсдийнх нь
бичлэгээс авсан.

- Сайт: `http://localhost:8000`
- Admin: `http://localhost:8000/admin`

## Онцлог

**Нийтийн тал**

- **Гурван хэл** — MN / EN / KR. Хөтчийн хэлээр анхны сонголтыг таамаглаж, дараа нь
  localStorage-д санана. Ө, Ү үсэг локал Open Sans фонтоор баталгаажсан (интернэтгүй үед ч зөв).
- **Динамик агуулга** — аялал, онцлох мөч, зургийн цомог, холбоо барих мэдээлэл бүгд
  өгөгдлийн сангаас. Хэл солиход хуудас дахин ачаалалгүй шинэчлэгдэнэ.
- **Монгол улс, нутаг нутгаараа** — зураг бүр **аймгийн хэлбэрээр** таслагдан газрын зураг
  дотор байрлана (21 аймаг + Улаанбаатар, `js/data/aimags.js`, geoBoundaries CC BY 4.0). Аймаг бүр
  өөрийн нутгийн (Говь / Хөвсгөл / Төв / Баруун) зургаас нэгийг авна. Нутгийн нэр дээр дарахад бусад
  нутаг бүдгэрнэ. Нүүрэнд доор нь зургууд нэг мөрөнд урсана; цомгийн хуудсанд нутаг бүрийн тор.
  Утсанд газрын зураг нуугдана. Дарахад lightbox (сум, гар, шүргэлтээр удирдана).
- **Өнгө** — брэнд нь Монголын хөх тэнгэр (гүн хөх, шөнийн хөх), гол товч логоны шар.
  Нутгийн өнгө: Говь улаан хад, Хөвсгөл teal, Төв талын ногоон. Газрын
  зураг, аяллын карт, шошго, дэлгэрэнгүй хуудасны хажуугийн самбар бүгд `data-region`-оор
  ижил өнгө авна (`base.css`-ийн `--rc` / `--rs`).
- **Аялал хуудас** — гурван карт (зураг, онцлох мөчүүд, улирал). Онцлох мөчүүд `/api/tours`
  жагсаалтад хамт ирдэг тул нэг л хүсэлт.
- **Холбоо барих** — Улаанбаатарын амьд цаг, гурван сувгийн карт, хуулаад л илгээх бэлэн
  мессеж (гурван хэлээр), түгээмэл асуулт.
- **Замын уртын багана** — өдрийн хуваарь бөглөсөн аялалд өдөр тутмын км график болж
  харагдана. Хоосон бол хэсэг нь огт гарахгүй.
- Гар утсанд бүрэн зохицсон (360 px-ээс дээш шалгасан), гар, товчлуураар удирдах боломжтой.

**Admin (`/admin`)**

- Хяналтын самбар — тоо, орчуулга дутуу аяллын жагсаалт, зургийн бүсийн харьцаа
- Аяллын CRUD — гурван хэл, нүүр зураг (байршуулах эсвэл цомгоос сонгох), онцлох мөч,
  багтсан/багтаагүй, өдрийн хуваарь (заавал биш)
- Зургийн цомог — байршуулах, засах, нуух, дараалал солих
- Тохиргоо — лого зураг, холбоо барих суваг (нэг л хуудас)

## Ажиллуулах

### 1. Шаардлага
Node.js **18+** (24 дээр туршсан), npm.

### 2. Суулгах
```bash
npm install
```

### 3. Тохиргоо
```bash
cp .env.example .env
```
`.env`-ийг нээж бөглөнө:

| Түлхүүр | Тайлбар |
|---|---|
| `SESSION_SECRET` | Урт санамсаргүй утга. `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"` |
| `ADMIN_USERNAME`, `ADMIN_PASSWORD` | Анхны admin. **АНХААР:** нууц үгэнд `#` эсвэл хоосон зай байвал заавал хашилтанд бич — эс бөгөөс dotenv `#`-ээс хойшхийг тайрна. Ж: `ADMIN_PASSWORD="Aa1#strong"` |
| `COOKIE_SECURE` | Production-д заавал `1` (зөвхөн HTTPS) |

> `.env` өөрчилсний дараа серверийг **дахин эхлүүл** — `node --watch` нь `.env`-г дахин уншдаггүй.

### 4. Өгөгдлийн сан
```bash
npm run db:migrate   # хүснэгтүүд
npm run db:seed      # 3 аялал, 30 зураг, тохиргоо, admin
```
Шинээр эхлэх бол: `npm run db:reset`

### 5. Ажиллуулах
```bash
npm start      # эсвэл npm run dev — өөрчлөлтөд автомат reload
```

## Архитектур

- **Backend** — Express 5 + `better-sqlite3`. Бүх query параметртэй (SQL injection-оос хамгаалсан).
  Оролтыг zod-оор шалгана; API зөвхөн зөвшөөрсөн талбарыг буцаана (`lib/serialize.js`).
- **Frontend** — vanilla ES module. DOM-д бичвэрийг зөвхөн `textContent`-ээр тавина
  (XSS-ээс хамгаалах), `innerHTML`-ийг зөвхөн өөрсдийн статик орчуулгын attribute-д ашиглана.
- **i18n** — статик бичвэр `data-en` / `data-kr` attribute-аар (MN нь DOM-ын анхны утга);
  динамик агуулга API-аас `{mn, en, kr}` хэлбэрээр ирж `pick()`-ээр сонгогдоно.
  Хэл солиход `langchange` event цацагдаж, харагдац дахин зурагдана.
- **Аюулгүй байдал** — helmet CSP (`script-src 'self'`, inline script байхгүй), httpOnly сесс
  cookie, бичих хүсэлт бүрд CSRF токен, scrypt нууц үг, нэвтрэлтэд rate limit,
  байршуулсан файлын нэрийг сервер өгнө (path traversal-аас хамгаалах).

## Production

```bash
npm run build
NODE_ENV=production COOKIE_SECURE=1 SERVE_DIR=dist node server/index.js
```

Node host (Render / Railway / Fly.io / VPS) дээр байршуулна. Тогтвортой дискэнд хадгалах ёстой:

- `server/data/app.db` — өгөгдлийн сан
- `server/uploads/` — admin-аас байршуулсан зураг

## Анхаарах

- **Утас, и-мэйл, KakaoTalk сувгийн холбоос хоосон байгаа.** Эдгээрийг компани нийтэлээгүй тул
  зохиомол утга оруулаагүй. Admin → Тохиргоо хэсэгт бөглөнө; хоосон талбар сайтад огт
  харагдахгүй.
- **Аяллын хугацаа тохиролцоно.** Компани тогтмол өдрийн тоо зарладаггүй (맞춤 여행) тул
  «Хугацаа тохиролцоно» гэж харуулна. Admin-аас өдрийн тоо оруулбал шууд солигдоно.
- **Зураг нь Wikimedia Commons-ынх** (CC0 / CC BY / CC BY-SA). Зохиогч бүрийг
  `public/images/gallery/CREDITS.json`-д бичсэн, admin дахь зураг бүрийн «Зохиогч / лиценз»
  талбарт шилжүүлсэн. Танай өөрсдийн зургаар солих нь зүйтэй.
- **Хэлний анхны сонголт** нь зочны хөтчийн хэлээр тодорхойлогдоно (солонгос хөтөч → KR).
  Толгойн MN / EN / KR товчоор гараар солино.
- **Дэлгэцийн зураг авахдаа** headless Chrome цонхыг ~500px-ээс нарийсгадаггүй тул гар утасны
  харагдацыг `public/` дотор түр `.htm` файлд 390px iframe-ээр нээж буулгана.
